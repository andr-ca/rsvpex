<objective>
Auto-login new hosts immediately after signup instead of requiring a second login.

When a new host signs up at /rsvp/admin/signup with valid email and password (12+ chars), the response should set a session_id cookie and redirect to /rsvp/admin (the dashboard) with a 303 status code, exactly like the POST /rsvp/admin/login flow does. The new host lands directly on their dashboard without a redundant login step.

Purpose: Reduce friction in the host signup UX; the host just entered their credentials, so they should be logged in immediately.

- adminSignup.ts: Import createSession + setCookie, call both after successful INSERT, redirect to /rsvp/admin with 303
- admin-signup.test.ts: Update test to verify 303 redirect, session_id cookie, and that the session works via a follow-up authenticated request
- All tests passing (typecheck, lint, format, vitest)
</objective>
