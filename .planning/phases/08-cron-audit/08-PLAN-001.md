# Phase 8: Cron & Audit — Implementation Plan

**Goal:** Reminder emails fire automatically N days before each event, old audit log rows are purged on a daily schedule, and every privileged admin action is durably recorded with PII-redacted diffs.

**Depends on:** Phase 7

**Requirements:** NOTIF-04, SEC-04

## Architecture

- `src/domain/audit.ts` — pure: PII redaction helper, JSON Merge Patch diff builder, `writeAuditLog` D1 insert
- `src/domain/cron.ts` — pure: query events where reminder is due today, batch reminder messages
- `src/handlers/queue.ts` — add `reminder` message type and handler
- `src/handlers/cron.ts` — replace stub: fire reminders + audit purge
- `src/routes/adminEvents.ts` — audit log on create/update/publish/archive
- `src/routes/adminRsvps.ts` — audit log on edit/delete/promote
